Teach software engineering as the discipline of governing capable, autonomous agents.

This companion provides materials for teaching software engineering using MAGE (Model-Based Agentic Software Engineering). The method is developed in full in the **[MAGE textbook](https://davisjam.github.io/model-based-agentic-software-engineering/book/)**.

The **[Reference Course](reference-course/index.md)** is ECE 30861 — Software Engineering, Purdue University, Fall 2026. It includes the syllabus, lecture materials, oral exams, and a semester-long project.

The **[Semester Project](project/index.md)** gives student teams a substantial problem through which to practice the concepts across the software lifecycle.
