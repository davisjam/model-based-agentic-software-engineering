Ask about the model system

Type to filter the questions this model system can answer; the list offers only questions its own models license. What you type is not read as English — for a question in your own words, ask your coding agent (it drives the same workbench through window.mage.ask), or open Advanced query below and state the question formally. A verdict is recomputed on every revision and stored nowhere, and it always says which models established it; a bounded search is reported as inconclusive, never as a no.

Ask a question

Graph questions only, from these controls. A behavioural question carries a state predicate — a nested conjunction over machine references — and a set of menus that could build one would be a worse query language than the structured source it replaces; write those in the file or send them through window.mage.query. Add a model

A model is a purposeful reduction, so the question it answers is required. It lists entities the system already declares; models reference, they never redeclare.

Remove a model

Refused while the model still asserts a relation. Remove those relations first: each one is an architectural claim, and nothing here will drop a claim as a side effect.

Attach a note

Context, not a constraint. A note changes nothing the model asserts and does not advance its revision, so analysis ignores it. To make an assumption bind a result, represent it as a property, a variable or a guard.
