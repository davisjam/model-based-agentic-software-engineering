Add a model

A model is a purposeful reduction, so the question it answers is required. It lists entities the system already declares; models reference, they never redeclare.

Remove a model

Refused while the model still asserts a relation. Remove those relations first: each one is an architectural claim, and nothing here will drop a claim as a side effect.

Attach a note

Context, not a constraint. A note changes nothing the model asserts and does not advance its revision, so analysis ignores it. To make an assumption bind a result, represent it as a property, a variable or a guard.

Properties and requirements

A property is a persistent claim about the system. Its verdict is recomputed every time the model changes and is stored nowhere, so what you read is always this revision's answer. Every verdict says which models and machines established it; a bounded search is reported as inconclusive, never as a no.

Ask a question

Graph questions only, from these controls. A behavioural question carries a state predicate — a nested conjunction over machine references — and a set of menus that could build one would be a worse query language than the structured source it replaces; write those in the file or send them through window.mage.query. Only relation types this model system declares are offered.

Save the question above as a property

What is saved is the question, never the answer: the verdict is recomputed on every later revision. State the claim as an assertion — "Restricted data cannot reach Analytics", not "Can restricted data reach Analytics?" — because the status word is read against it. Declaring an expectation makes it a requirement: a differing outcome then counts as a failure rather than a finding.

Stop evaluating a property

The claim is removed from the model system, so no later revision evaluates it. The models it was about are untouched.

Provenance

Where each object came from, and what its author was asked to preserve. Provenance is context rather than constraint: reading it cannot change an answer, and recording it does not advance the model's revision.
