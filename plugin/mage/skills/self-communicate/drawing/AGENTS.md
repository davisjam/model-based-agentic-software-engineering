# Drawing

Visual representations for structures, relationships, teaching figures, measurements, and tabular comparisons.

Choose the representation according to the information being communicated. Use the editorial figure guidance before the realization resource when the visual is teaching a concept. Do not create a diagram merely because prose seems visually plain.

1. **Editorial judgment** — `figures.md`
   Decide what a teaching figure should communicate and how much it should show.
2. **Representation** — `diagrams.md`, `charts.md`, `tables.md`
   Choose and realize the appropriate visual form.
3. **Format audit** — `svg-audit.py`
   Validate hand-authored drawing artifacts where applicable.
