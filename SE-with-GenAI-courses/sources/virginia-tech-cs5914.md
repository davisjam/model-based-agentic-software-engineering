## A. Explicit course content (quoted / cited)

### Identity
Virginia Tech · Department of Computer Science · CS 5914 (graduate special study / special topics) · "AI Tools for Software Delivery" · Spring 2024 · Instructor: Steven Atkinson · graduate (explicitly "designed for master's students") · format not stated.

### Stated learning objectives
Verbatim (from the special-topics page): "Upon completion, students should:
1. 'Discuss the history of and differences between AI, machine learning and data science.'
2. 'Identify key features of AI and ML technologies such as supervised and unsupervised learning, generative text-based large-language models and know when to apply these technologies.'
3. 'Discuss ethical and social issues related to adoption of AI tools in software development.'"

Additionally: students will "have built a tool to store and organize prompts for AI engines, populated with a collection of prompts demonstrating software development principles."

Course description, verbatim opening: "This course is specifically designed for master's students who have an interest in gaining knowledge about Artificial Intelligence (AI) and Machine Learning (ML) and how they are utilized in software development." The page states the course examines AI/ML applications in software development — large language models, recommendation engines, image classification, natural language processing — and that the primary focus is "leveraging generative AI for code generation, code analysis, testing, and documentation" (per the page's description of course scope).

## B. Surveyor notes (interpretation, labeled)
- **Coverage gaps:** severe — the entire public record is a one-page special-topics description. No syllabus, schedule, assignments, readings, or tool list is public. Most fields above are "not observable," not "not taught." Evidence strength: thin.
- **Organizing logic (interpretation):** the description suggests a two-part shape: (a) AI/ML literacy for software professionals (history, taxonomy, when-to-apply — outcomes 1–2), then (b) applying generative AI across software-delivery activities, culminating in a prompt-library tool. The reusable-prompt-collection capstone implies the course treats *prompting as a codifiable engineering asset* — a notably practice-oriented framing — but no public material shows how (or whether) verification, oversight, or governance of AI output is taught.
- **Classification reasoning (interpretation):** core comparator on the stated center of mass ("how [AI/ML] are utilized in software development", generative AI for code gen/analysis/testing/docs). The AI-fundamentals outcomes are background literacy, not building AI systems, so "mixed" seems wrong; but the thin record makes this classification low-confidence.
