# Evidence file template

One file per candidate course: `sources/<institution>-<course>.md`. Everything in §A must be
verbatim-quoted or precisely cited from a primary source (URL + section). §B is the surveyor's
reading, labeled as such. Where public material does not cover a field, write
**"not evident in available materials"** — never assume absence from the real course.

```
# <Institution> — <Course number and title>

**Gathered:** <date> · **Preliminary class:** core / mixed / exclude (reason)

## Sources consulted
- <URL> — <what it is: syllabus / course site / instructor GitHub / registrar / lecture schedule>
- (note any material that is known to exist but is not publicly reachable)

## A. Explicit course content (quoted / cited)
### Identity
university · department · number · title · term/year · instructor(s) · level (UG/grad) · format
### Stated learning objectives
(verbatim where possible)
### Organizing sequence
(lecture/unit/week sequence as published)
### Assignments and project structure
### AI tools and agent frameworks used
### Readings
### Treatment of: conventional SE activities
### Treatment of: human responsibility and judgment
### Treatment of: evaluation/verification of AI-produced work
### Treatment of: persistent engineering knowledge beyond source code
### Treatment of: controls, constraints, governance, enforcement

## B. Surveyor notes (interpretation, labeled)
- coverage gaps in the public record
- preliminary reading of the course's organizing logic (marked as interpretation)
```
