# Northwestern COMP_SCI 397 — Applied AI for Software Development

Spring 2025 · Hamilton Murrah · senior UG / MS, ~30 students ·
[evidence](../sources/northwestern-cs397.md)

## What it teaches

A practicum: two weeks of comparative tool calibration ("testing how tools like ChatGPT, Cursor,
and Claude.ai handled tasks such as debugging, refactoring, and exploring natural language coding
though pseudocode"), then a sustained team build of a full-stack Twitter-style application —
backend, frontend, database design, integration — with AI assistance throughout, plus architecture
design documents "tracking decision-making processes," stand-ups, and interviews with practicing
engineers.

## How it is organized (interpretation)

Calibrate the tools, then build something real with them. The visible intellectual stance is
"foundational skill is the multiplier on the tool" (Murrah: "These tools are only as good as the
user, and if you don't start with a solid base of foundational skills and functional knowledge,
how can you ever use a tool to its full potential?") — not a taxonomy of AI-SE techniques.
