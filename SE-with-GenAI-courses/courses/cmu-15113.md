# CMU 15-113 — Effective Coding with AI

Spring 2026 (first offering) · Mike Taylor · undergraduate, open across majors, 15-112 successor ·
[evidence](../sources/cmu-15113-effective-coding-with-ai.md)

## What it teaches

Combining intermediate programming skill with AI tools to build complete applications weekly,
while "collectively develop[ing] standards for maintaining code quality, transparency, and ethical
integrity in AI-augmented workflows." Three phases: tools & exploration (prompting, APIs) →
strategic mastery (server-side, ethics, databases) → capstones (agentic workflows, phone apps,
RAG). Projects require deployed apps, public repos, and a mandatory prompt log "documenting AI
tools used, development process, code authorship, and key prompts." The AI policy is
attestation-plus-oral-verification: "Explain AI-generated code in your own words," "never commit
code you can't explain reasonably well," and instructors "may ask students to explain submitted
code and their creation process."

## How it is organized (interpretation)

Guided co-discovery. The class itself produces the normative artifact — a living "Best Practices
and Lessons Learned" page distilled from student experience across nine assignments, including
"Plan before coding: write detailed plans or SPEC.md files with acceptance criteria before
implementation" and "Document thoroughly: leave READMEs... and prompt logs for whoever inherits
the code—including future you." The intellectual center is calibrated reliance: speed from AI,
quality and understanding guaranteed by the human, enforced socially (oral defense, prompt logs)
rather than technically. Instructor retrospective: "the students who learned the most were the
ones who refused to let the AI think for them."

## Adoptability (drop-in availability, audited 2026-09-30)

**Category 1 — drop-in / canned course.** The Spring 2026 archive is a self-contained package —
syllabus, dated schedule, 22 decks, every graded artifact, and a pilot-run retrospective — but it
states no license, so an adopter must ask.

- **Public:** full syllabus with AI-use policy · dated 14-week schedule · 22 downloadable lecture
  decks · 10 of 10 graded artifacts with standalone instructions · published grade weights · setup
  guides · demo repositories · a 12,000-word retrospective on the pilot run, which is the kind of
  artifact an adopter almost never gets.
- **Absent:** the quiz and exam bank.
- **Login:** none for instructional content. Ed Discussion and the Google Forms submission links are
  enrolled-student mechanics.
- **License:** **no license stated.** The S26 index and the best-practices report carry no
  "copyright", "©", "Creative Commons", "all rights reserved", or "license" string; the three demo
  repos return `license: null`.
- **Checked:** `cs.cmu.edu/~mdtaylor/113/S26/` and its schedule, best-practices, and project pages;
  `cs.cmu.edu/~113/`; the three demo repos via the GitHub API.
