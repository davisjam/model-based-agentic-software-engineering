# Virginia Tech CS 5914 — AI Tools for Software Delivery

Spring 2024 · Steven Atkinson · master's ·
[evidence](../sources/virginia-tech-cs5914.md)

## What it teaches (as far as observable)

AI/ML literacy for software professionals (history, taxonomy, when-to-apply) plus "leveraging
generative AI for code generation, code analysis, testing, and documentation." The one public
capstone artifact: students "have built a tool to store and organize prompts for AI engines,
populated with a collection of prompts demonstrating software development principles."

## How it is organized (interpretation, low confidence)

Two-part shape: AI/ML fundamentals, then generative AI applied across software-delivery
activities, culminating in a prompt-library tool — which implies the course treats prompting as a
codifiable, persistent engineering asset. Nothing public shows how verification, oversight, or
governance of AI output is taught.

## Evidence caveat

Severe: the entire public record is a one-page special-topics description. Among the earliest
courses in the corpus (Spring 2024), which partly explains the thin trail. Classification as core
is low-confidence.

## Adoptability (drop-in availability, audited 2026-09-30)

**Category 4 — essentially closed.** One unlinked catalog blurb is the entire public record.

- **Public:** a standalone special-topics page — a heading bar, a one-paragraph description naming
  subject areas, and three learning outcomes. Its raw HTML was pulled and every `href` extracted: the
  **anchor list is empty**. The page links to nothing, including Canvas.
- **Absent:** no syllabus, no grading breakdown, no policies, no schedule, no sequence, **zero**
  slides, **zero** assignments, no readings, no rubrics, no setup instructions, no prerequisites. The
  capstone gets one sentence: "you will have built a tool to store and organize prompts for AI
  engines, populated with a collection of prompts demonstrating software development principles" —
  with no requirements, milestones, or rubric.
- **Login:** the blurb itself is open. There is no public path to any actual material.
- **License:** **no license stated** — no copyright notice and no terms of any kind.
- **Why 4 rather than 3:** a ~200-word description does not make the course's intellectual content
  visible the way a real syllabus or the Passau paper does. There is nothing to inspect *and* nothing
  to reuse.
- **Checked:** the VT special-topics page (200, raw HTML and anchor list extracted); two WebSearches
  for a course site, repository, syllabus PDF, or the prompt-library tool — all of which surfaced only
  the same blurb, the VT index, static grad course descriptions, and an enrollment listing.
