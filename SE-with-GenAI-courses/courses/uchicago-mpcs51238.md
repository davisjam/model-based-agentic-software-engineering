# UChicago MPCS 51238 — Design, Build, Ship

Spring 2026 (also Summer 2025, Autumn 2026) · Andre Fiuza Marques · MPCS graduate elective ·
[evidence](../sources/uchicago-design-build-ship.md)

## What it teaches (as far as observable)

"Transform ideas into launched products and services with real users in 10 weeks. This hands-on
course focuses on iterative design and rapid software development, using AI-assisted tools to
accelerate the entire process." One quarter-long project per student or small team: build, launch,
and acquire users. The program article's framing contrasts it with courses that "prioritize
polished final presentations" — the emphasis is "launching early and testing with real users."

## How it is organized (interpretation)

A lean-startup shipping practicum in which generative-AI development tools are the enabling
accelerant rather than an object of study. It plausibly teaches engineering-with-AI by immersion;
the public record shows no explicit pedagogy about directing, verifying, or governing AI-produced
work.

## Evidence caveat

Thin: catalog paragraph (recovered via search renderings — the listing page has a broken TLS
chain) plus one program marketing article. No syllabus, schedule, grading, or tool list public.
Classification as core is provisional; it should be revisited if a syllabus surfaces showing an
entrepreneurship course that merely permits AI tooling.
