# CU Boulder CSCI 7000-11 — GenAI-powered Software Engineering

Fall 2025 · Danny Dig · graduate seminar (remote, no exam) ·
[evidence](../sources/cu-boulder-csci7000-genai-se.md)

## What it teaches

"Seminal topics and recent trends in the field of GenAI for Software Engineering," anchored in
maintenance-side practice: refactoring (extract method, move method, extract class, code smells,
agentic refactoring), large-scale migration ("Migrating Code At Scale With LLMs At Google"), test
generation and repair, program repair, API documentation, effort estimation — two recent venue
papers per session, bracketed by systematic surveys and three industrial keynotes. Objectives
include "critically assess AI-assisted development workflows" and "hands-on experience using GenAI
in tasks such as testing, debugging, code synthesis, and refactoring." Students may substitute a
"Tool Experience Report" (hands-on use of a paper's tool) for a critique; the semester project may
be "novel-industrial" — applying GenAI frameworks/principles/practices to an SE task — as an
alternative to research.

## How it is organized (interpretation)

A research seminar with an unusually strong practice anchor: the topic spine is software
maintenance and evolution (the instructor's research lineage — RefactoringMiner), with GenAI as
the new instrument. Human-agent collaboration appears as studied content ("Why AI Agents Still
Need You"). The critique-or-tool-report option and the industrial project track deliberately admit
practitioner-mode engagement.
