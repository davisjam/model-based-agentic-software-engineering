## Six additions in the manuscript

1. **Persistent context.** The agent making a change and the agent reviewing it later can consult the same declared dependencies even when they share no conversation. The model can be mistaken or misread. Enforcing a dependency rule requires a mechanism that acts on it.
2. **Scope and assumptions.** Equal daily request totals can conceal different arrival patterns. An agent reusing a steady-arrival capacity estimate can check its assumptions against burst measurements from the proposed deployment.
3. **Granularity.** A service view exposes architectural boundaries. A class- or function-level view exposes the users of a particular interface. The chosen detail affects both human review and the information an agent must reconstruct.
4. **Delegated decisions.** The engineer fixes the sorting obligation and timing tolerance. The agent may choose its algorithm. Showing one algorithm as scaffolding leaves the other acceptable implementations available.
5. **Selective retrieval.** Starting with a service identifier, an agent can retrieve its dependencies, owner, deployment, and requirements within a bounded context window. The recorded relations and the query determine which relevant facts it receives.
6. **Model validation.** Exhaustive search can miss a real failure if the model omitted its transition. Observed traces, experiments, and domain knowledge give the engineer independent evidence about whether the model is adequate for its question.

Two passages carry the final editorial refinements. On granularity, the manuscript reads, “Engineers can maintain views at different levels of detail for people, for agents, or for both. Even for the same task, a less capable agent may need an intermediate view showing which classes implement the interface. A stronger agent may reliably reconstruct those relationships from the service model and the available code.” The validation passage reads, “An agent can perform a correct analysis of an inadequate model.” The next sentences identify the evidence that can expose an omitted transition.
